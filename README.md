# @kibalabs/ui-react-dropzone

**Moved to `@kibalabs/ui-react/dropzone`.** This package is no longer maintained.

```bash
npm uninstall @kibalabs/ui-react-dropzone
npm install @kibalabs/ui-react react-dropzone
```

Then replace imports of `@kibalabs/ui-react-dropzone` with `@kibalabs/ui-react/dropzone`. Styles move from `@kibalabs/ui-react-dropzone/styles.scss` (`.css`) to `@kibalabs/ui-react/dropzone/styles.scss` (`.css`).
